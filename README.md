# Module 2: Web App Deployment using Flask

## Project Name: Employee Directory Flask App

### Project Details
This is a Flask-based Employee Directory web application developed for Module 2 Graded Assignment.

Description:
A lightweight web app that allows managers to view and revise employee contact details. The app demonstrates Flask routing, view functions, handling of GET, POST, PUT, and PATCH requests, and deployment concepts.

Key Features:
- View employee list (GET)
- Add new employee (POST)
- Update / Revise employee contact details (PUT / PATCH)
- Delete employee (DELETE)
- RESTful API endpoints returning JSON (application/json)
- Flask default 200 OK response handling

Tech Stack:
- Python 3.x
- Flask
- REST API
- HTML / JSON
